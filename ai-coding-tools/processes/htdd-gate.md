# HTDD gate

Open this file only when `docs/htdd/AGENTS.md` exists at the repository root. Read it before any implementation. Leave it closed when that file is absent.

Follow `docs/htdd/AGENTS.md` and `docs/htdd/MILESTONES/CURRENT.md` in the product repository. This file is the gate. It is not the method.

## Write this before editing product code

1. The governing milestone folder, taken from `docs/htdd/MILESTONES/CURRENT.md`.
2. Whether this task is specification, implementation, repair, evidence, or a contract change.
3. If the task adds a screen, collection, access path, search, invitation channel, or a local copy of memorial content, quote the milestone line that allows it. If you cannot quote it, stop.
4. If the task changes a sentence that appears in a milestone contract, update that contract in the same change, or stop.
5. A quality-pass milestone is not permission to add product.
